 一人财税 · OPC创业者轻量化智能财税工具
面向一人公司、个体工商户、自由职业者打造的轻量化财税工具，基于 Python + Streamlit 开发，深度接入 WorkBuddy AI 智能体，支持自然语言指令完成账单分类、税额测算、经营报表生成。

项目定位
针对 OPC 单人创业者「代账成本高、自己报税难、财务软件操作复杂」的行业痛点，以极低的使用成本，提供标准化的记账、算税、报表全流程辅助服务，助力单人创业者低成本、高效率完成日常财税管理。

核心功能
1. 智能账单自动分类
基于内置关键词规则库，自动区分收支大类与明细分类，支持单笔快速打标、批量账单统一处理。

2. 月度税额精准测算
适配小规模纳税人现行税收优惠政策，自动计算增值税、附加税、个人经营所得税及综合税负率，内置起征点判断、阶梯式计税逻辑。

3. 经营报表一键生成
批量读取 CSV 格式账单，自动完成全量单据分类，汇总收支盈亏数据，生成结构化报表并保存本地，配套可视化趋势图表。

4. 财税政策动态更新
内置政策爬虫模块，自动采集公开财税政策，同步更新系统计税规则库，保障算税标准与官方政策同步。

技术架构
采用「业务逻辑与交互、AI调用分离」的分层解耦设计，网页端与AI端复用同一套核心规则，计算结果统一可控。

| 层级 | 对应文件 | 核心职责 |
| :--- | :--- | :--- |
| 业务核心层 | `tax_utils.py` | 收支分类、税额测算、批量账单处理纯业务逻辑 |
| Web交互层 | `one_person_finance.py` | Streamlit 可视化网页，图形化操作界面 |
| MCP服务层 | `mcp_server.py` | 基于 FastMCP 封装标准化工具，对接 WorkBuddy |
| 数据层 | CSV账单文件 | 本地账单存储与报表输出 |

快速运行
1. 安装依赖：`pip install -r requirements.txt`
2. 启动网页：`streamlit run one_person_finance.py`
3. MCP 接入 WorkBuddy（stdio 模式）：
```json
{
  "mcpServers": {
    "one_person_finance": {
      "command": ".venv/Scripts/python.exe",
      "args": ["mcp_server.py"],
      "cwd": "./"
    }
  }
}
